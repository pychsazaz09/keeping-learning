## Python 装饰器
（写什么是装饰器、怎么用、和 FastAPI 路由装饰器的关系）
装饰器本质：接收函数作为参数，返回一个新的包装函数，在不修改原函数代码的前提下，给函数增加额外逻辑（日志、计时、鉴权、异常捕获）。
## asyncio 事件循环
（写事件循环是什么、await 做了什么、和 Java 线程模型的区别）
事件循环 (event‑loop) 是 asyncio 的核心调度器，单线程内部的任务管理器。
一个线程里跑一个事件循环；
维护任务队列，轮流调度可运行的协程；
遇到 IO 等待（网络请求、数据库、sleep）就把当前协程挂起，切换执行其他就绪协程；
IO 完成后，切回来继续执行剩下代码。
asyncio 是单线程并发，不是多线程。靠 IO 等待间隙切换任务实现高并发。
2.await 到底做了什么
await xxx 后面必须是可等待对象（coroutine 协程、Task）
把当前协程挂起交出控制权，让出事件循环；
等待 IO 操作完成（数据库、http 请求）；
IO 就绪后，事件循环恢复这个协程，继续往下执行后面代码。
## FastAPI Depends 依赖注入
（写 Depends 怎么管理生命周期、yield 的作用）
Depends()是 FastAPI 实现依赖注入工具，用于抽离公共逻辑：获取 db 会话、鉴权、获取请求对象。
默认：每个请求到来，就新建一次依赖实例；请求结束后销毁。
作用域：默认是scope="request"，一次 HTTP 请求完整生命周期。
每来一次 http 请求，就执行一遍Depends(get_db)；多个接口共享同一个请求内的依赖结果。
yield用来做资源的申请 + 资源释放（上下文管理），实现请求结束后的清理工作。
